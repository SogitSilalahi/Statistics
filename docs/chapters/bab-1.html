1.1 Tiga Distribusi yang Harus Dibedakan

Distribusi Isinya Jumlah nilai Contoh

Distribusi sampling adalah konsep teoretis: dalam praktik kita hanya memiliki satu sampel. Namun dengan simulasi kita dapat “melihatnya”.

1.1.1 Populasi Simulasi

Kita memakai populasi 20.000 mahasiswa dengan variabel waktu layar harian (jam) yang menjulur kanan - bentuk yang sengaja dipilih jauh dari lonceng.

set.seed(909)
N        <- 20000
populasi <- round(rgamma(N, shape = 2, rate = 0.4), 2) # jam per hari
mu       <- mean(populasi)
sigma    <- sqrt(mean((populasi - mu)^2))                 # SD populasi (pembagi N)
c(N = N, mu = round(mu, 3), sigma = round(sigma, 3))
        N        mu     sigma 
20000.000     5.010     3.551

Interpretasi. Populasi terdiri dari N = 20.000 mahasiswa dengan rata-rata waktu layar (𝜇) sekitar 5 jam per hari dan simpangan baku (𝜎) sekitar 3,5 jam. Nilai ini sesuai dengan sifat distribusi gamma yang dibangkitkan (mean = shape/rate = 2/0,4 = 5; SD = √2/0,4 ≈ 3,54). 𝜎 yang hampir sebesar 𝜇 menandakan data sangat beragam dan menjulur kanan. Kedua angka ini adalah parameter populasi, yaitu nilai “kebenaran” yang nanti akan ditaksir dari sampel.

set.seed(1)
satu_sampel <- sample(populasi, 40)
banyak_rata <- replicate(10000, mean(sample(populasi, 40)))

xlab = "Jam per hari", xlim = c(0, 20))

Populasi dan satu sampel sama-sama menjulur kanan, tetapi distribusi rata-rata sampel jauh lebih sempit dan hampir berbentuk lonceng. Inilah inti pertemuan ini.

Interpretasi. Histogram biru (populasi) dan oranye (satu sampel, n = 40) sama-sama berbentuk miring ke kanan: sebagian besar mahasiswa memiliki waktu layar rendah sampai sedang, dan sedikit orang memiliki waktu layar yang sangat panjang. Histogram oranye lebih “kasar” karena hanya berisi 40 data, tetapi masih meniru bentuk populasi. Histogram hijau (distribusi sampling 𝑥̄) berbeda: bentuknya simetris menyerupai lonceng, terpusat di sekitar 𝜇 ≈ 5 jam, dan sebarannya jauh lebih sempit (sekitar 4 sampai 6 jam, sedangkan data individu berkisar 0 sampai lebih dari 15 jam). Artinya rata-rata sampel jauh lebih stabil daripada nilai individu, dan bentuknya normal walaupun populasinya tidak.

Interpretasi. Kurva merah adalah distribusi normal dengan mean 𝜇 dan SD 𝜎/√𝑛. Semakin besar 𝑛: (1) distribusi semakin sempit, dan (2) bentuknya semakin mendekati normal meskipun populasinya menjulur kanan.

Interpretasi. Pada n = 5 (SE ≈ 1,58) histogram masih sedikit miring ke kanan dan kurva normal belum pas sempurna. Pada n = 20 (SE ≈ 0,79) bentuknya sudah jauh lebih simetris, dan pada n = 80 (SE ≈ 0,40) histogram hampir berimpit dengan kurva merah. Garis putus-putus (𝜇) selalu berada di pusat, sehingga ukuran sampel tidak mengubah pusat distribusi (tetap tak bias), tetapi mengecilkan sebaran dan memperbaiki kenormalan. Ketika n naik 4 kali lipat dari 5 ke 20 dan dari 20 ke 80, SE turun kira-kira separuhnya (1,58 → 0,79 → 0,40), sesuai hukum akar kuadrat.

1.3 Central Limit Theorem (CLT)

Central Limit Theorem. Jika sampel acak berukuran 𝑛 diambil dari populasi sembarang bentuk dengan mean 𝜇 dan simpangan baku 𝜎 (terhingga), maka untuk 𝑛 yang cukup besar, distribusi sampling ̄𝑥 mendekati normal

\[\bar{x} \approx N\left(\mu, \frac{\sigma}{\sqrt{n}}\right)\]

CLT adalah alasan mengapa distribusi normal muncul di mana-mana dalam statistika inferensial–bukan karena data selalu normal, tetapi karena rata-rata dari data cenderung normal.

1.3.1 Demonstrasi pada Tiga Bentuk Populasi

set.seed(3)
pop_bentuk <- list(
"Seragam" = runif(20000, 0, 10),
"Menjulur kanan" = rexp(20000, rate = 0.5),
"Bimodal" = c(rnorm(10000, 2, 0.8), rnorm(10000, 8, 0.8))
)
ukuran <- c(2, 5, 30)
par(mfrow = c(4, 3), mar = c(3, 3, 2.5, 1))
for (nama in names(pop_bentuk)) {
hist(pop_bentuk[[nama]], breaks = 40, col = "#9ecae1", border = "white",
main = paste("Populasi:", nama), xlab = "", ylab = "")
}
for (nn in ukuran) {
for (nama in names(pop_bentuk)) {
rata <- replicate(3000, mean(sample(pop_bentuk[[nama]], nn)))
hist(rata, breaks = 35, col = "#a1d99b", border = "white",
main = paste0(nama, ", n = ", nn), xlab = "", ylab = "")
}
}
par(mfrow = c(1, 1), mar = c(5, 4, 4, 2) + 0.1)

Baris pertama adalah populasi; baris berikutnya adalah distribusi sampling ̄𝑥 untuk 𝑛 = 2, 5, dan 30. Populasi seragam sudah tampak lonceng pada 𝑛 = 5; populasi bimodal masih bergelombang pada 𝑛 = 2 tetapi lonceng pada 𝑛 = 30; populasi menjulur kanan membutuhkan 𝑛 terbesar untuk menghilangkan kemencengannya.

Interpretasi. Tiga populasi di baris pertama sangat berbeda: datar (seragam), miring tajam (eksponensial), dan berpuncak dua (bimodal). Namun pada n = 30 ketiga distribusi rata-rata sampel tampak simetris berbentuk lonceng. Ini adalah inti CLT: bentuk populasi “dilupakan” ketika kita beralih ke distribusi rata-rata. Bedanya hanya pada kecepatan konvergensi: populasi seragam (simetris) cepat normal, bimodal baru menyatu setelah n cukup besar karena dua puncaknya harus “terhapus”, dan eksponensial paling lambat karena kemencengannya paling kuat. Kesimpulannya, CLT berlaku untuk populasi apa pun, tetapi kata “cukup besar” bergantung pada bentuk populasi.

1.3.3 Menghitung Peluang dengan CLT

Contoh: Jika diambil sampel acak 40 mahasiswa, berapa peluang rata-rata waktu layarnya melebihi 5,5 jam?

\[z = \frac{\bar{x} - \mu}{\sigma / \sqrt{n}} \qquad P(\bar{x} > 5,5) = P(Z > z)\]

se40 <- sigma / sqrt(40)
z_55 <- (5.5 - mu) / se40
c(SE = round(se40, 4), z = round(z_55, 3),
Peluang_CLT = round(1 - pnorm(z_55), 4),
Peluang_simulasi = round(mean(banyak_rata > 5.5), 4))
              SE                z      Peluang_CLT Peluang_simulasi 
          0.5615           0.8730           0.1913           0.1803

Interpretasi. Dengan SE ≈ 0,56, nilai 5,5 jam berada sekitar z ≈ 0,89 simpangan baku di atas 𝜇. Peluang CLT bahwa rata-rata 40 mahasiswa melebihi 5,5 jam adalah sekitar 0,19 (±19%). Peluang hasil simulasi 10.000 sampel hampir sama dengan angka CLT, sehingga pendekatan normal dapat dipercaya pada n = 40 walaupun populasinya menceng. Selisih kecil antara keduanya wajar karena simulasi mengandung kesalahan acak dan sedikit sisa kemencengan.

Perbandingan: peluang seorang mahasiswa (bukan rata-rata 40 orang) memiliki waktu layar di atas 5,5 jam jauh lebih besar:

mean(populasi > 5.5)
[1] 0.35175

Interpretasi. Sekitar 35% mahasiswa secara individu memiliki waktu layar di atas 5,5 jam, hampir dua kali lipat dari peluang untuk rata-rata 40 mahasiswa (sekitar 19%). Alasannya, nilai individu sangat bervariasi (SD ≈ 3,5), sedangkan rata-rata kelompok “menyaring” nilai ekstrem sehingga jauh lebih terkonsentrasi di sekitar 5. Jadi peluang untuk individu dan peluang untuk rata-rata tidak boleh dicampur.

Individu sangat bervariasi, tetapi rata-rata dari banyak individu jauh lebih stabil.

1.5.2 Hukum Akar Kuadrat

Karena 𝑆𝐸 ∝ 1/√𝑛, untuk membagi dua SE dibutuhkan sampel empat kali lipat. Presisi semakin mahal: menambah 𝑛 dari 100 ke 400 memberi keuntungan yang sama dengan dari 400 ke 1.600.

Interpretasi. Kurva turun tajam di awal lalu melandai. Titik merah menunjukkan n = 100 dengan SE ≈ 0,35 dan n = 400 dengan SE ≈ 0,18: menambah 300 responden hanya memangkas SE separuhnya. Setelah n sudah besar, tambahan sampel memberi peningkatan presisi yang makin kecil (diminishing returns), sehingga ada titik di mana menambah sampel tidak lagi sebanding dengan biayanya.

1.6 Estimasi

1.6.1 Point Estimate

Point estimate adalah satu angka yang menaksir parameter.

Parameter *Point estimate* Penaksir tak bias?
$\mu$ $\bar{x}$ Ya
$p$ $\hat{p}$ Ya
$\sigma^2$ $s^2$ (pembagi $n - 1$) Ya
$\sigma$ $s$ Sedikit bias (diabaikan dalam praktik)

Kelemahan point estimate: hampir pasti tidak tepat sama dengan parameter, dan tidak memberi tahu seberapa jauh melesetnya.

Interpretasi. Tabel memasangkan setiap parameter dengan penaksirnya: 𝑥̄ untuk 𝜇, 𝑝̂ untuk 𝑝, s² untuk 𝜎², dan s untuk 𝜎. Ketiga yang pertama tak bias. s sedikit bias ke bawah karena akar kuadrat dari penaksir tak bias tidak otomatis tak bias, tetapi bias ini kecil sehingga diabaikan. Karena satu angka tidak menyatakan ketidakpastian, kita membutuhkan selang kepercayaan.

1.6.2 Confidence Interval (Selang Kepercayaan)

Selang kepercayaan memberikan rentang nilai yang masuk akal bagi parameter:

\[\text{Point estimate} \pm \underbrace{\text{nilai kritis} \times SE}_{\text{margin of error}}\] #### CI untuk Mean, 𝜎 Diketahui (z)

\[\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\]

sigma_k / sqrt(n_k)
[1] 1

Jawaban: SE = 6/6 = 1 gram. Rata-rata dari 36 kemasan biasanya meleset sekitar 1 gram dari rata-rata sebenarnya jauh lebih kecil daripada variasi berat antarkemasan (6 gram).

Interpretasi. Output 1 berarti SE = 1 gram: jika pengambilan 36 kemasan diulang berkali-kali, rata-rata sampelnya akan bervariasi dengan simpangan baku 1 gram di sekitar rata-rata sebenarnya mesin. Presisi taksiran rata-rata (1 gram) enam kali lebih baik daripada keragaman kemasan individu (6 gram).

Tugas 2: Jika mesin bekerja benar (𝜇 = 250), berapa peluang rata-rata 36 kemasan kurang dari 248 gram?

pnorm(248, mean = 250, sd = sigma_k / sqrt(n_k))
[1] 0.02275013

Jawaban: 𝑧 = (248 − 250)/1 = −2, sehingga peluangnya sekitar 0.0228. Kejadian ini jarang jika mesin bekerja benar – gagasan yang menjadi dasar uji hipotesis di Pertemuan 10.

Interpretasi. Peluangnya 0,0228 (sekitar 2,3%). Jika mesin benar-benar mengisi rata-rata 250 gram, hanya sekitar 2 dari 100 sampel berukuran 36 yang rata-ratanya kurang dari 248 gram. Karena kejadian ini jarang, bila rata-rata sampel kita memang sekitar 248 gram, kita punya alasan untuk curiga bahwa mesin tidak bekerja sesuai target.

Tugas 3: Hitung CI 95% untuk rata-rata berat (𝜎 diketahui)

ci_z <- mean(berat) + c(-1, 1) * qnorm(0.975) * sigma_k / sqrt(n_k)
round(c(x_bar = mean(berat), Bawah = ci_z[1], Atas = ci_z[2]), 2)
 x_bar  Bawah   Atas 
247.40 245.44 249.36

Interpretasi. Dengan 𝜎 diketahui, margin of error = 1,96 × 1 = ±1,96 gram. Selang yang diperoleh berpusat pada rata-rata sampel (sekitar 248 gram) dengan lebar total 3,92 gram. Kita 95% yakin bahwa rata-rata pengisian mesin yang sebenarnya berada di dalam selang tersebut. Karena target 250 gram berada di luar selang, data tidak mendukung klaim bahwa rata-rata mesin 250 gram.

Tugas 4: Hitung CI 95% jika 𝜎 dianggap tidak diketahui (t)

round(t.test(berat)$conf.int, 2)
[1] 245.25 249.56
attr(,"conf.level")
[1] 0.95
round(c(s = sd(berat), t_kritis = qt(0.975, 35), z_kritis = qnorm(0.975)), 3)
       s t_kritis z_kritis 
   6.366    2.030    1.960

Interpretasi. Output pertama adalah selang t 95% yang lebarnya mirip selang z. Output kedua menunjukkan s ≈ 6 (dekat dengan 𝜎 = 6), t kritis = 2,030 (df = 35), dan z kritis = 1,960. Karena t kritis sedikit lebih besar dari z kritis (selisih sekitar 3,6%), selang t sedikit lebih lebar sebagai “harga” atas penaksiran 𝜎 dengan s.

Tugas 5: Tafsirkan hasilnya

Jawaban: Selang z dan selang t sangat mirip karena 𝑛 = 36 cukup besar (t kritis hanya sedikit di atas 1,96) dan 𝑠 dekat dengan 𝜎. Jika nilai 250 tidak berada di dalam selang, data memberi indikasi bahwa rata-rata pengisian mesin berbeda dari target – yang dapat dikonfirmasi dengan uji hipotesis. Hasil sampel ini: 250 berada di luar selang z.

Interpretasi. Kedua selang menghasilkan kesimpulan yang sama, yaitu nilai 250 gram berada di luar selang sehingga rata-rata pengisian mesin diduga lebih rendah dari target (sekitar 1,5 sampai 2 gram di bawah). Dari sisi bisnis, ini berarti kemasan cenderung kurang isi, yang berisiko pada kepuasan pelanggan dan kepatuhan label berat. Kesimpulan ini masih berupa indikasi dari selang kepercayaan, dan pembuktian formalnya (H₀: 𝜇 = 250) dilakukan dengan uji hipotesis di Pertemuan 10.

Tugas 6 (Tantangan): Ukuran sampel

Berapa kemasan yang harus diambil agar margin of error CI 95% hanya ± 1 gram? Dan ± 0,5 gram?

c(MoE_1 = n_mean(sigma = 6, E = 1), MoE_0.5 = n_mean(sigma = 6, E = 0.5))
  MoE_1 MoE_0.5 
    139     554

Jawaban: 139 kemasan untuk ± 1 gram dan 554 kemasan untuk ± 0,5 gram – membagi dua margin of error membutuhkan sampel empat kali lipat

Interpretasi. Sampel saat ini (36) memberi MoE ±1,96 gram. Untuk menurunkannya menjadi ±1 gram dibutuhkan 139 kemasan, dan untuk ±0,5 gram dibutuhkan 554 kemasan. Dari 139 ke 554 (naik sekitar 4 kali), MoE hanya turun separuh. Perusahaan perlu menimbang biaya pengambilan sampel QC terhadap presisi yang dibutuhkan.

1.9.2 Latihan Tambahan (Self-Check)

Kerjakan soal-soal berikut secara mandiri sebelum melihat kunci jawaban pada komentar kode.

Soal A. Waktu tunggu layanan pelanggan berdistribusi menjulur kanan dengan 𝜇 = 8 menit dan 𝜎 = 6 menit. Untuk sampel acak 64 panggilan, tentukan mean, SE, dan bentuk distribusi sampling , lalu hitung ̄𝑥 𝑃( ̄𝑥 > 9).

# Kunci jawaban:
# Mean = 8; SE = 6 / sqrt(64) = 0.75; bentuk mendekati normal (CLT, n = 64)
1 - pnorm(9, mean = 8, sd = 0.75) # z = 1.33 -> sekitar 0.0912
[1] 0.09121122

Interpretasi. Distribusi sampling 𝑥̄ berpusat di 8 menit dengan SE 0,75 menit dan berbentuk mendekati normal berkat CLT (n = 64 cukup besar). Peluang rata-rata 64 panggilan melebihi 9 menit adalah sekitar 0,0912 (9,1%). Jadi rata-rata waktu tunggu 9 menit atau lebih termasuk jarang, tetapi bukan mustahil, bila rata-rata sebenarnya 8 menit.

Soal B. Survei 1.200 pemilih menunjukkan 54% mendukung sebuah kebijakan. Hitung CI 95% dan margin of error-nya.

# Kunci jawaban:
p <- 0.54; n <- 1200
moe <- qnorm(0.975) * sqrt(p * (1 - p) / n) # 0.0282 -> +- 2.8 poin persentase
p + c(-1, 1) * moe # 0.512 sampai 0.568
[1] 0.511801 0.568199

Interpretasi. Margin of error ≈ ±2,8 poin persentase sehingga CI 95% adalah 51,2% sampai 56,8%. Seluruh selang berada di atas 50%, jadi survei ini menunjukkan dukungan mayoritas yang cukup meyakinkan. Jika selangnya mencakup 50% (misalnya 48% sampai 54%), kesimpulan “mayoritas mendukung” tidak bisa ditarik dengan yakin.

Soal C. Sepuluh pengukuran pH air limbah: 6,8; 7,1; 6,9; 7,4; 7,0; 6,7; 7,2; 7,3; 6,9; 7,1. Hitung CI 95% untuk rata-rata pH secara manual dengan distribusi t lalu periksa dengan t.test().

ph <- c(6.8, 7.1, 6.9, 7.4, 7.0, 6.7, 7.2, 7.3, 6.9, 7.1)
# Kunci jawaban:

Interpretasi. Rata-rata pH sampel 7,04 dengan CI 95% 6,885 sampai 7,195, dan t.test() memberikan selang yang sama. Kita 95% yakin bahwa rata-rata pH air limbah berada di antara 6,89 dan 7,20, yaitu sekitar netral. Karena n hanya 10, harus dipakai t (kritis 2,262, bukan 1,96).

1.10 Kesalahan Umum dalam Sampling Distribution dan Estimasi

  1. Menyamakan distribusi sampel dengan distribusi sampling – yang pertama berisi data individu, yang kedua berisi statistik dari banyak sampel.
  2. Mengira CLT membuat data menjadi normal – CLT berbicara tentang distribusi ratarata, bukan data individu.
  3. Menganggap 𝑛 ≥ 30 selalu cukup – data yang sangat menceng atau beroutlier bisa membutuhkan lebih.
  4. Menyamakan SD dan SE – SD mengukur keragaman individu; SE mengukur ketepatan taksiran.
  5. Memakai z padahal 𝜎 tidak diketahui dan 𝑛 kecil – gunakan distribusi t.
  6. Menafsirkan CI sebagai peluang parameter berada di dalam selang tertentu, atau sebagai rentang nilai individu.
  7. Membulatkan ukuran sampel ke bawah – selalu bulatkan ke atas.
  8. Mengira ukuran populasi menentukan ukuran sampel – untuk populasi besar, yang menentukan adalah margin of error, tingkat kepercayaan, dan variabilitas.
  9. Mengira sampel besar menghilangkan bias – ukuran sampel hanya mengecilkan galat acak.
  10. Memakai pendekatan normal untuk proporsi saat 𝑛 ̂𝑝 atau 𝑛(1 − ̂𝑝) kurang dari 10.
  11. Melaporkan point estimate tanpa selang atau 𝑛 – pembaca tidak dapat menilai ketepatannya.

1.13 Rangkuman dan Kesimpulan

  1. Distribusi sampling menggambarkan bagaimana sebuah statistik bervariasi dari sampel ke sampel; ia adalah fondasi seluruh statistika inferensial.
  2. ̄𝑥 dan ̂𝑝 adalah penaksir tak bias dengan SE masing-masing 𝜎/√𝑛 dan √𝑝(1 − 𝑝)/𝑛.
  3. CLT menjamin distribusi ̄𝑥 mendekati normal untuk 𝑛 cukup besar, apa pun bentuk populasinya; makin menceng populasi, makin besar𝑛 yang dibutuhkan.
  4. SE bukan SD: SE mengecil sebanding 1/√𝑛 – presisi dua kali lipat membutuhkan sampel empat kali lipat.
  5. Selang kepercayaan = point estimate ± nilai kritis × SE. Gunakan z bila 𝜎 diketahui, t bila 𝜎 ditaksir. Kepercayaan 95% adalah sifat prosedur, bukan peluang untuk satu selang.
  6. Ukuran sampel dapat direncanakan dari margin of error yang diinginkan – tetapi tidak dapat menyembuhkan bias sampling.
